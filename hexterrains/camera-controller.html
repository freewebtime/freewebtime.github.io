    📷 Camera Controller System

    The Hex Terrains Framework includes a built-in camera controller system that allows users to smoothly move and zoom the camera across a hex terrain during gameplay or editing. This system is built on top of Unity ECS and integrates seamlessly with both UI input and ECS logic.

    Overview

    The camera controller is composed of the following parts:

    • Authoring + Baking: Declares movement keys and speed settings.
    • ECS Systems: Create, update, and clean up camera controller components.
    • Scene Component: A CameraControllerComponentBase instance handles zoom behavior and actual camera movement.

    This design enables camera panning, zooming, and follow behavior over ECS-controlled hex terrains with minimal boilerplate.

    Components

    CameraControllerAuthoring (MonoBehaviour)

    This Unity MonoBehaviour is placed on a GameObject to configure the camera movement and zoom behavior. It includes:

    • Movement input keys (WASD or others)
    • Acceleration key (e.g., Shift)
    • Speed settings
    • Flags to indicate terrain wrapping (horizontal/vertical)

    It gets baked into a CreateCameraControllerRequest component.

    public class CameraControllerAuthoring : MonoBehaviour
{
    public KeyCode MoveUpKey = KeyCode.W;
    public KeyCode MoveDownKey = KeyCode.S;
    public float MovementSpeed = 10f;
    public bool IsConnectedHorizontally;
}

    CreateCameraControllerRequest (IComponentData)

    Added to a terrain entity during baking. When processed, it creates a runtime camera controller for the terrain.

    public struct CreateCameraControllerRequest : IComponentData
{
    public KeyCode MoveUpKey;
    public float MovementSpeed;
    public bool IsFindCameraControllerComponentOnScene;
}

    CameraControllerTarget (ICleanupComponentData)

    Attached to a terrain entity, it contains:

    • Current movement input config
    • Camera target local position
    • Pointer to CameraControllerComponentBase MonoBehaviour
    • UnityObjectRef<Transform> for target GameObject movement

    Systems

    CreateCameraControllerSystem

    • Executes in the HexTerrainsInitializationGroup
    • Detects CreateCameraControllerRequest and adds CameraControllerTarget
    • Instantiates a new Transform for the camera to follow
    • Optionally binds a CameraControllerComponentBase found in the scene

    Automatically positions the camera over the center of the terrain at start.

    UpdateCameraControllerSystemBase

    • Handles input (W, A, S, D, Shift) and applies movement to the camera target
    • Wraps around terrain borders if IsConnectedHorizontally/Vertically is set
    • Updates zoom or world position if any movement occurred
    • Calls CameraControllerComponentBase.UpdatePosition()
    • Updates the minimap view via IMinimapScreen

    Ignores input if the pointer is over UI (using EventSystem.current.IsPointerOverGameObject())

    DestroyCameraControllerSystem

    • Executes in HexTerrainsCleanupGroup
    • Cleans up camera targets when terrain becomes invisible or is removed

    Camera Controller Component

    CameraControllerComponentBase (MonoBehaviour)

    A Unity-side component for zooming and final camera positioning. You can implement custom behaviors by deriving from this class. For example, it supports:

    • CurrentZoom value in range [0–1]
    • Computed offset between MinZoomOffset and MaxZoomOffset
    • SetTarget() and UpdatePosition() abstract methods

    How to Use

    1. Add CameraControllerAuthoring to a GameObject.
    2. Add a derived implementation of CameraControllerComponentBase to the scene.
    3. Assign your terrain entity with the authoring component.
    4. At runtime, camera controller will be initialized and updated automatically.
    5. Optionally override UpdateCameraControllerSystemBase.GetMinimapScreen() to sync with your UI.

    Extending

    • You can create custom camera behavior by subclassing CameraControllerComponentBase.
    • For advanced use cases (e.g., cinematic camera), you may implement your own systems and disable the default ones.

    🧪 Sample Camera Controller (SamplesCameraControllerComponent)

    To help users quickly integrate and test the camera system, the Hex Terrains Framework includes a ready-to-use MonoBehaviour: SamplesCameraControllerComponent. This is a simple but flexible camera rig with zooming, panning, and edge wrapping.

    🔍 Purpose

    This component demonstrates how to:

    • Integrate the ECS-based camera logic with a Unity Camera component
    • Follow a target (usually a terrain anchor or camera proxy)
    • Implement smooth zooming using the mouse scroll wheel
    • Avoid UI conflicts (prevents movement if pointer is over UI)
    • Enforce terrain boundaries and edge-wrapping logic

    🧱 Inherits From

    public class SamplesCameraControllerComponent : CameraControllerComponentBase

    📌 Features

    • Zoom Control Uses Input.mouseScrollDelta.y to change zoom, clamped between 0 and 1.

    • Target Following The camera follows a world Transform provided by ECS using SetTarget().

    • Zoom Modifier Keys If the user is holding modifier keys like LeftAlt or LeftControl, zoom is temporarily disabled to avoid accidental input.

    • Acceleration Holding the acceleration key (e.g., Shift) increases zoom speed via AccelerationMultiplier.

    • UI-Aware Input Prevents updates when the user interacts with UI using EventSystem.current.IsPointerOverGameObject().

    🧪 Sample Usage

    public Camera camera;
public SamplesCameraControllerComponent controller;

controller.Camera = camera;
controller.SetTarget(cameraFollowTransform);  // Set by ECS at runtime

    🔁 Zoom Calculation Logic

    var scrollDelta = Input.mouseScrollDelta.y * ZoomSpeed;
CurrentZoom += scrollDelta * multiplier;
CurrentZoom = Mathf.Clamp(CurrentZoom, 0, 1);

    The final zoom offset is applied to the camera using:

    Camera.transform.position = TargetTransform.TransformPoint(CurrentZoomOffset);
Camera.transform.LookAt(TargetTransform);

    🚫 Zoom Lock Keys

    By default, zoom is disabled while any of the following keys are held:

    KeyCode.LeftAlt
KeyCode.LeftControl

    This is defined in:

    public List<KeyCode> PreventZoomKeys

    You can customize this list at runtime or via inspector.

    🧩 Integration Tip

    This is a great starting point for integrating with custom terrain views, minimaps, or input contexts. For a more advanced camera (e.g., orbit or drag-scroll), simply subclass this component or extend CameraControllerComponentBase.
