    CalculateCellValueColorsJob_Byte

    Job that calculates a color for cell based on cell value. Calculates a lerp progress of the cell value between MinValue and MaxValue, then takes the respective color from the ColorPalette by applying the progress to the palette, so first item in palette is MinValue, last item is MaxValue. If there are more colors in color palette, they together form a gradient between MinValue and MaxValue.
