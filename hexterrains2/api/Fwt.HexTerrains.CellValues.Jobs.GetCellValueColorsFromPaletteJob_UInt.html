    Remarks

    This job processes each cell in parallel, mapping cell values to colors based on the provided palette. Only cells within chunks marked as dirty in the chunk dirty grid are updated. If a cell value does not correspond to a valid palette index, the default color is used. This struct is intended for use with Unity's job system and Burst compiler for efficient, multithreaded processing of large terrain datasets.
