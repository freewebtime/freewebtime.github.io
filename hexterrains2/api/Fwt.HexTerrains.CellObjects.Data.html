    Namespace Fwt.HexTerrains.CellObjects.Data

    Classes

    CellObjectLayer

    Terrain layer that contains a visual object per cell. Renders cell objects using Graphics.DrawMeshInstanced using provided BulkRenderer and CellObjectConfigs.

    CellObjectLayerConfigAsset

    CellObjectLayerGroup

    Structs

    CellObjectConfig

    Configuration for a cell object (visual object that is placed in a cell). Contains a list of states, each state can have multiple LODs (Level of Detail). States allow to have different visuals for the same cell object, for example, a forest can have different visuals when it's young or fully grown or a building can have different visuals when it's under construction or fully built or it's a ruins.

    CellObjectLODConfig

    Configuration for a cell object LOD (Level of Detail). Contains a range of distances for which this LOD is used, and a list of render entities (meshes, materials, etc.) that are used to render this LOD. Also holds a relative transforms for each render entity, which allows to place them correctly in the cell space.

    CellObjectStateConfig

    Configuration for a cell object state. Each cell object can have multiple states, for example, a tree can be young, fully grown or a stump, the building can be under construction, fully built or a ruins.
