    Remarks

    This job is designed for use with Unity's Burst compiler and the job system to efficiently process large terrain datasets. It updates the color map by evaluating mineral data for each cell, using a color palette and configurable minimum and maximum thresholds to determine the resulting color and transparency. Only cells within chunks marked as dirty for mineral index or amount are recalculated, optimizing performance for dynamic terrain updates.

    Fields

    ColorMap

    Output array of colors that are filled in the job. Each cell's color is determined based on the mineral index and amount, using the provided color palette and thresholds. The alpha value of the color is calculated to represent the transparency based on the mineral amount relative to the defined minimum and maximum values.

    DefaultColor

    Color that is used if the mineral index or amount is out of range of the provided color palette or min/max thresholds. This color can be set to a default value (e.g., transparent) to indicate that no valid mineral data is present for a cell. The job will return this color for any cell where the mineral index exceeds the bounds of the color palette or where the mineral amount is outside the defined minimum and maximum thresholds. This ensures that cells with invalid or missing mineral data are visually distinguishable in the resulting color map.
