    What's next

    📍 Roadmap: Hex Terrains Framework

    The Unity Asset Store reviews every package update manually, which may take some time (in some cases, up to a month). To make the most of this review cycle, my goal is to submit each new update as soon as the previous one gets approved and published.

    🔜 In the Near Future

    • More documentation Including tutorials, use-case guides, and new video demonstrations.

    ✅ First Update

    • Improved ByteArea Terrain Layers (used for countries, provinces, etc.)

    • Simplified access to cells belonging to a given area.

    • Bug fixes (if any are discovered).

    • If you find a bug, please report it here: 👉 GitHub Issues

    ⏭ Planned Next Update

    • Chunk Mesh Generator Enhancements

    • Chunk Game Objects (with colliders)

    • LODs for Cell Items

    • Save Terrain Mesh in Unity Editor to prefab

    • Support for mapping biomes to specific UV atlas sections (reducing submesh count).

    • Extended mesh API for custom cell geometry generation.

    • Road System

    • Per-chunk road meshes.

    • Custom road mesh generator support.

    • Units System

      • Each unit is a standalone ECS entity.
      • Serializable unit data.

    • Built-in pathfinding support (initial version).

    • Custom Data Layers

      • Blittable struct per cell.
      • Optional color map for visualization.
      • Works similarly to existing byte-based area layers.

    • User-Suggested Features

      • High priority will be given to community feedback and feature requests.

    🧩 Possible Future Features (Under Consideration)

    Here are some features I may explore based on demand or personal roadmap:

    • Dynamic Weather or Environmental Layers

    • Per-cell temperature, moisture, elevation deltas for climate simulations.

    • DataLayer Serialization Enhancements

    • Visual inspectors for chunk states, dirty grids, and job timings.

    • Out-of-the-box Gameplay Examples

    • Mini simulation scenes (e.g., “hex farming”, “unit movement”, “political map”).

    💬 How You Can Contribute

    Have an idea or a request? Feel free to open a discussion or issue: 👉 Discord
