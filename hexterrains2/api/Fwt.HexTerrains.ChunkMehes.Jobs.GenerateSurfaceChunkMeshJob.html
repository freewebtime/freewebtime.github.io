    Remarks

    This struct is intended for use with Unity's Job System and Burst compiler to efficiently generate mesh data in parallel. It processes the provided chunk and cell metrics, applying terrain and rendering settings to produce mesh data suitable for rendering hexagonal terrain with biome-specific UVs and colored borders. The job requires all referenced data (such as cell metrics and biome UVs) to be properly initialized before execution. Mesh generation is skipped if the mesh data source is not initialized.
