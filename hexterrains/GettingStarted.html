    Getting Started

    Samples Demo Scene

    1. Install package from asset store.

    2. Open Package Manager window (Window -> Package Manager)

    3. Select the Fwt.HexTerrains package

    4. In right section of the window find tabs "Description", "Version History", "Dependencies", "Samples". Select "Samples"

    5. Import HexTerrains Demo core sample

    6. Additionally import one of two following samples depending on your render pipeline: "HexTerrains Demo URP assets" or "HexTerrains Demo HDRP assets"

    7. After sample projects are imported into your project, navigate to folder "Assets/Samples/HexTerrains/HexTerrains_URP" or "Assets/Samples/HexTerrains/HexTerrains_HDRP" depending on your render pipeline.

    8. From there navigate to "Scenes" folder and open Showcase scene

    9. Press "Play" button

    10. Select "System" User Tool category, then "Create New"

    11. In openned window select a terrain prefab and put the settings you want.

    12. Press "Create" button

    13. Enjoy!

    In-game terrain editor

    1. In-game editor is a State Machine called UserToolStateMachine

    Create terrain on scene load

    1. You can find Terrain prefabs in the Samples folder by path "Assets/Samples/Fwt.HexTerrains/1.0.0/HexTerrains_URP/Prefabs" for URP projects and by path "Assets/Samples/Fwt.HexTerrains/1.0.0/HexTerrains_HDRP/Prefabs" for HDRP projects

    2. Put a prefab you want on the "Showcase Subscene" subscene besides the HexTerrainEditor prefab. Then add the reference to this Terrain on the HexTerrainEditor game object at "Terrain Authoring" field of SamplesUserToolDataAuthoring component

      Note: if you don't set a reference to the terrain on the HexTerrainEditor, you will not be able to edit a terrain using the User Tools Panel at the bottom center of the screen.

      Note: HexTerrainEditor prefab is optional. It is needed for having the User Tools Panel to be created. For your gameplay it might not be needed, so feel free to get rid of it.
